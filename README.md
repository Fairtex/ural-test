# Деталь

Одностраничное приложение для подбора автозапчастей. По артикулу оно находит производителей, по выбранному производителю показывает исходную деталь и аналоги с ценами и остатками по складам.

## Запуск

По умолчанию приложение работает с демонстрационными данными.

```sh
docker compose up --build
```

Откройте [localhost:5173](http://localhost:5173). Для запуска с установленным Node.js 24:

```sh
npm ci
npm run dev
```

## Что попробовать

- Нажмите **01089** и выберите одного из десяти производителей. В списке работают стрелки, Home, End и Enter.
- Нажмите **7160500039S**, выберите **MEYLE** и прокрутите предложения. В демо для этой пары 1 829 строк, включая позиции без наличия. Нажатие на заголовок цены или остатка меняет сортировку.
- Измените артикул, пока идёт запрос. Выбранный бренд и прежняя выдача сбросятся сразу. Введите неизвестный артикул, чтобы увидеть пустой результат.

Демонстрационные цены, остатки и аналоги синтетические. Статический каталог загружается по HTTP. В DevTools можно замедлить сеть, проверить отмену запроса или заблокировать загрузку каталога и повторить запрос после восстановления сети.

## Реальный API

Скопируйте `.env.example` в `.env`, установите `VITE_DATA_MODE=live` и заполните `FAVORIT_API_KEY` ключом покупателя. Перезапустите Vite или повторите `docker compose up --build`, затем введите артикул.

Браузер обращается к локальному `GET /api/parts`. Прокси Vite добавляет ключ на сервере и запрашивает `https://api.favorit-parts.ru/hs/hsprice/`. Первый запрос передаёт `number`, второй — также `brand` и `analogues=on`. Ключ хранится в окружении локального сервера. Подробности — в [документации поставщика](https://lk.favorit-parts.ru/static/wsprice.pdf).

Одна строка соответствует складу исходной детали или аналога. Цена берётся из `warehouses[].price`, остаток — из `warehouses[].stock`. Позиции с нулевым общим остатком без складов показываются с остатком 0 и прочерком в цене.

## Устройство

React и Vite, JavaScript, Bootstrap CSS. Код сценария находится в `src/features/parts-search`:

- `api` — RTK Query, выбор источника и общее преобразование ответов.
- `model` — ввод и выбор, debounce 400 мс, отмена запросов и проверка актуальности результата.
- `ui` — список брендов и таблица с виртуализацией TanStack Virtual, состояния загрузки, ошибки и повтор запроса.

## Проверка и публикация

```sh
npm run lint
npm run build
npm run preview
```

Для публикации демо выберите в репозитории **Settings → Pages → Source → GitHub Actions**. При отправке ветки `main` workflow выполнит линт, соберёт проект в режиме `demo` и опубликует `dist`. Доступен и ручной запуск из вкладки Actions. Для работы статического демо на GitHub Pages ключ не требуется.
